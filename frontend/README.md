# CareerMate

CareerMate is an AI-powered career management platform designed to help students manage their job search, analyze resumes, discover relevant opportunities, and prepare for interviews.

## 🚀 Features

- Resume analysis
- Job and skill matching
- Application tracking
- Interview preparation
- Career dashboard
- Resume management
- Cover letter support
